# Research & References

This file contains the research papers, data sources, portals, APIs, and open-source tools referenced in the project.

- Publisher: Psychological Assessment Resources

### [2] Frey, C. B., & Osborne, M. A. (2017)
**The Future of Employment: How Susceptible Are Jobs to Computerisation?**

- Journal: *Technological Forecasting and Social Change*, 114, 254–280

**Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks.**

- Conference: EMNLP-IJCNLP 2019
- Pages: 3982–3992
- DOI: https://doi.org/10.18653/v1/D19-1410

## 2. Data Sources and Portals

### NIRF Rankings
Official National Institutional Ranking Framework (Ministry of Education, Government of India).

- https://www.nirfindia.org/

### National Scholarship Portal (NSP)
Official Government of India scholarship portal.

- https://scholarships.gov.in/

### Vidya Lakshmi Portal
Education-loan information and application portal.

- https://www.vidyalakshmi.co.in/

### Adzuna API
Job-ad and employment-data API used for salary/job-market information.

- https://developer.adzuna.com/
- API overview: https://developer.adzuna.com/overview

## 3. Open-Source Tools

### NetworkX
Python package for creation, manipulation, and study of complex networks.

- https://github.com/networkx/networkx
- Documentation: https://networkx.org/

### scikit-learn
Machine-learning library for Python.

- https://github.com/scikit-learn/scikit-learn
- Documentation: https://scikit-learn.org/

### FastAPI
Python web framework for building APIs.

- https://fastapi.tiangolo.com/

### React Flow
React library for building node-based editors and interactive diagrams.

- https://reactflow.dev/

### Faiss
Library for efficient similarity search and clustering of dense vectors.

- https://github.com/facebookresearch/faiss

## 4. Notes

- External data sources and APIs may change their availability, endpoints, or terms of use.
- Where an API requires credentials (for example, Adzuna), API keys should be stored in environment variables and **never committed to GitHub**.
- This document is intended as a project reference list; consult the original sources for the authoritative research and current data.
